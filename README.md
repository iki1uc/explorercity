ZAM – Orbit-Engine (iki1uc)
ZAM ist die Orbit‑Einheit des iki1uc‑Systems.
Es bildet den aktiven Kreis zwischen KlicK, ZaM, Orbit, Peak und Rückführung.

ZAM verbindet:

PX3 / PX6 / PX9 (PX‑TRIO)

PX12 / PX4 (Fusion + Achse)

SYS / SYS‑x (System + Kreuzung)

TEM (Zeit)

GEO (O12 / F4 / XU / TO)

KlicK.ZaM (Orbit‑Impuls)

vitality (Tiefe / Energie)

io.reverse / oi.reverse (Rückführung)

ZAM erzeugt:

Orbit‑Rotation

Orbit‑Erfüllung

Peak‑Punkt

Rückführung

Synchronisation

ZaM‑Level
